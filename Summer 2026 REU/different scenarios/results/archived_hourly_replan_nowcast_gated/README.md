# Archived Hourly-Replan Nowcast-Gated Scenario Results

This folder preserves the older Step 3 result set where the scenario controller replans every hour and uses the nowcast/gated labels. These are the results that produce the 3-scenario winning table used in the current manuscript revision.

Key settings represented by these CSVs:

- 48-hour lookahead
- first-hour execution / hourly replanning
- current-hour nowcast plus causal ridge future forecasts
- 100 MW / 10-hour CAES comparison benchmark
- wind-only shown as secondary reference

The copied hourly CSV files are the source records used to rebuild `uncertainty_aware_summary.csv`.
