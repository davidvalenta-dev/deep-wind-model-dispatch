# Required Terminology

This document records the naming and time terminology requested by Dr. Chris
Qin. These names should be used consistently in reports, slides, code comments,
and result files.

## Required Case Names

| Required term | Meaning |
| --- | --- |
| Wind-only baseline | No storage. Actual wind is delivered directly subject to the 249 MW grid export cap; excess wind is curtailed. |
| 100-MW Constant-Output Baseload Benchmark | Rule-based wind-storage operation that tries to maintain 100 MW output using actual wind and CAES. |
| H-hour Perfect-Information Oracle Rolling-Horizon MILP | Gurobi sees actual future wind and actual future RTM price for H hours, executes only the first hour, and repeats. |
| Deterministic Forecast-Driven Rolling-Horizon MILP | Gurobi uses one realizable future forecast trajectory, such as forecast wind and a point price forecast. |
| Scenario-Based Rolling-Horizon MILP | Gurobi uses multiple possible future wind/price scenarios and a shared first-stage action. |
| Full-Horizon Oracle MILP | Gurobi uses actual wind and price for the full evaluation period; this is the absolute perfect-information upper bound. |

## Required Time Terms

| Term | Allowed meaning |
| --- | --- |
| Historical window | Past information used to construct forecast features. |
| Forecast horizon | Future period generated by the forecast model. |
| Planning horizon | Future period included in one optimization problem. |
| Execution step | Portion of the optimized plan that is actually executed. |
| Replanning interval | Time between two consecutive optimization runs. |
| Forecast lead time | Distance between the forecast origin and one future predicted time. |
| Evaluation period | Complete historical backtest or validation period. |

## Mandatory Rule

Use "historical window" only for past information.

Use "horizon" only for future information.

Avoid ambiguous labels such as "window hours" or "horizon hours" unless the
label says which kind of horizon it means, for example:

- planning_horizon_hours
- forecast_horizon_hours
- oracle_information_horizon_hours
