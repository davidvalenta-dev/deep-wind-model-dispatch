# Experiment Registry

This folder records canonical experiment metadata.

The main file is:

```text
experiment_registry.csv
```

It maps each important case to:

- status
- runner
- commit
- dataset
- wind and price sources
- evaluation period
- planning horizon
- execution step
- storage settings
- revenue
- COVE
- output file

The first registry entries are the July 2026 advisor-required canonical cases:

- 100-MW Constant-Output Baseload Benchmark
- 24-hour Perfect-Information Oracle Rolling-Horizon MILP
- 48-hour Perfect-Information Oracle Rolling-Horizon MILP
- 168-hour Perfect-Information Oracle Rolling-Horizon MILP
